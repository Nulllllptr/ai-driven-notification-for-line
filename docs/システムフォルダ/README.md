# 採番台帳

`docs/システムフォルダ/`配下のファイル番号を一元管理する。新規採番の前に必ずここを確認する。

## 採番ルール
- システム: 100刻み(100, 200, 300…)。空いている最小の100の倍数を割り当てる
- コンポーネント: 所属システム番号+1から連番(例: システム100番のコンポーネントは101, 102…)
