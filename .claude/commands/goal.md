# /goal: 独自の完了条件での自走ループ

引数(完了条件): $ARGUMENTS

コンポーネント単体の実装・修正は、依頼された時点で`design-doc-guard`4-1節の自走ループが常に
自動的に使われる(本コマンドを起動しなくてよい)。本コマンドはそれとは別に、複数コンポーネントに
またがる目標や、仕様書の受け入れ条件そのものとは異なる完了条件を開発者が指定したいときに使う。

## 1. 開始前の確認

- 完了条件が引数で与えられていない場合、実装せずその場で聞く。推測で進めない
- 対象範囲(1つのコンポーネントに閉じるか、複数コンポーネントにまたがるか)を確認する
- 対象コンポーネントの仕様書が存在しない場合、`design-doc-guard`4節に従い先に仕様書を作成し、
  開発者の同意を得てから2へ進む

## 2. ループ本体・停止条件・終了時の報告

`design-doc-guard`4-1節のループ(実装→`component-test-guard`→独立サブエージェントでの
`code-review-guard`→突き合わせ→修正)・停止条件・終了時の報告をそのまま用いる。判定基準だけ、
「仕様書の受け入れ条件」ではなく引数で指定された完了条件に置き換える。手順を重複定義しない。
