# 技術スタック・開発方針

## 1. インフラ構成
クラウド/オンプレの別、主要リソース(ネットワーク・実行環境・データストア等)を箇条書きで。
未確定の間は「未確定」と明記する。推測で埋めない。

## 2. 技術スタック(実装に追従して更新)
言語・フレームワーク・主要ミドルウェアをプロジェクト全体で列挙する。バージョンも分かれば記載。
個々のシステム固有の技術スタックは各システム単位設計書「4. 技術スタック」を参照。

## 3. ビルド・実行コマンド
開発・ビルド・デプロイの主要コマンドを列挙する。未実装の間は「未実装」と明記する。

## 4. 環境変数
必要な環境変数と用途を列挙する。値そのものは書かない(secrets-lifecycle-guardの対象)。

## 5. 開発方針(このプロジェクトで有効なユニット)
`.claude/skills/` `.claude/rules/` のうち、このプロジェクトで有効化しているものを列挙する。
