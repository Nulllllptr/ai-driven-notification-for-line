# プロダクト概要

## 1. プロジェクトの目的
開発者本人が、AI駆動開発(手法・ツールの動向、および要件定義/レビュー人材需要の変化など
市場動向)に関する最新情報を毎朝キャッチアップする手間を省く。
毎日9:00に、直近6ヶ月程度の情報から3件の記事にまとめてLINEへ自動通知する。

## 2. 対象ユーザー・利用シーン
開発者本人(個人利用)。LINE公式アカウントを友だち追加した自分自身の端末に、毎朝9:00の
通知として受け取る。

## 3. 提供する価値
- AI駆動開発に関する情報収集(手法・動向の巡回)を自動化する
- 「手法・技術動向」だけでなく「需要変化(要件定義・レビュー人材の需要増等)」も対象に含め、
  技術面と市場面の両方を押さえる
- 一度取り上げた情報・類似記事を繰り返し配信しないことで、情報の鮮度と非重複性を保つ
- 完全ローカル実行を避け、外部サービス(GitHub Actions・LINE Messaging API)のみで完結させる
